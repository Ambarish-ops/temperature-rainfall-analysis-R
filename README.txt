# Temperature and Rainfall Trends Using R — Final Tiny Project

FILES
-----
1. temperature_rainfall_tiny_project.Rmd
   The editable R Markdown source.

2. temperature_rainfall_tiny_project.html
   Working HTML output report. It opens directly in a browser and contains the
   analysis, R code, calculated results and embedded graphs.

3. weather_data.csv
   The dataset used by the project.

4. temperature_trend.png
5. rainfall_trend.png
6. temperature_rainfall.png
   Graphs used in the report.

REPRODUCING THE REPORT IN RSTUDIO
---------------------------------
1. Put the Rmd and CSV files in the same folder.
2. Open the Rmd file in RStudio.
3. Install the required package if needed:
   install.packages(c("rmarkdown", "knitr"))
4. Click Knit -> Knit to HTML.

The Rmd is written to use only the CSV dataset supplied with this project.
